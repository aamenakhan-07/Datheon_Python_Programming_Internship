Datheon Python Programming Internship

This repository contains Python projects completed as part of the Datheon Python Programming Internship.

Task 1: Hangman Game

A word-guessing game developed using Python. The player guesses letters to find the hidden word before running out of attempts.

Files:

- "hangman.py" – Main game code.
- "words.txt" – Word list used by the game.
- "extract_words.py" – Helper script for extracting words.

Task 2: Stock Portfolio Performance Tracker

A Python program that calculates the performance of stock holdings using sample stock prices.

Features:

- Accepts stock ticker symbols, purchase prices, and quantities.
- Calculates invested amount and current portfolio value.
- Calculates profit or loss and its percentage.
- Exports the results to a CSV file.

Files:

- "portfolio.py" – Main program.
- "portfolio_summary.csv" – Sample portfolio results generated by the program.

Note: The tracker currently uses sample stock prices, not live market data.

Technologies Used

- Python
- CSV file handling
- Dictionaries
- Basic calculations and input validation

Purpose

These projects demonstrate basic Python programming, problem-solving, data handling, and file operations as part of the internship.
