Hangman Word Guessing Game

Project Overview

This project is a Python-based Hangman Word Guessing Game developed as part of my Python Programming Internship.

The player tries to guess a randomly selected word by entering one letter at a time.

Features

- Random word selection from an external word list.
- Letter-by-letter guessing.
- Tracking of incorrect guesses.
- Maximum of six incorrect guesses.
- Win and game-over messages.
- Displays the correct word when the player loses.

Project Files

- "hangman.py" — Main game program.
- "words.txt" — Word list used by the game.
- "extract_words.py" — Script used to extract words from the supplied PDF word list.

Requirements

- Python 3
- The "words.txt" file must be in the same working folder as "hangman.py".

How to Run

1. Keep "hangman.py" and "words.txt" in the same folder.
2. Run "hangman.py" using Python.
3. Enter one letter when prompted.
4. Guess the hidden word before reaching six incorrect guesses.

Learning Outcomes

This project helped me practise Python basics, loops, conditional statements, user input, random selection, and file handling.
